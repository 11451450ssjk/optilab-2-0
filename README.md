# OptiLab 光电与电子信息本科—研究生实验与科研助手

这是面向光电信息科学与工程、电子信息本科生与研究生的浏览器端实验和科研助手，覆盖本科实验、研究训练、原理演示、数据处理、论文草稿和科研协作。

## 主要功能

- 实验笔记式入口：先说明“找实验、看步骤、整理数据”三个使用步骤，并可直接进入对应区域，避免打开后直接落入密集内容。
- 日夜主题：支持深色科研工作台与暖色日间界面，主题选择保存在本机。
- 晨光科研打卡：包含问候、连续天数、周视图、今日重点、投入时间、心情和简短提醒；打卡记录会连接到科研项目审阅。
- 独立第二页：欢迎页之后先进入独立 `checkin.html` 晨光提示页，完成或跳过打卡后再进入实验与科研工作台。
- 科研项目工作台：按“研究问题、假设、设计、文献、统计、报告、审阅”组织项目，并支持项目文件导入和导出。
- 文献全文知识库：在本机解析 PDF、TXT 和 Markdown，支持全文检索、证据卡片以及把手工整理的文献线索写入论文草稿。
- AI 实验设计助手：结合当前实验原理、器材条件、项目输入、实验报告和知识库内容，生成本地实验设计建议。
- 科研统计：支持线性、二次、对数、指数和幂律模型比较，并计算 AIC/BIC、残差、A/B 类合成不确定度、扩展不确定度、近似信噪比、探测限和重复组 ANOVA。
- 可复现研究包：导出项目档案、原始与清洗数据、统计快照、全文资料、报告、论文草稿、审阅记录和 Python 复算脚本。
- 本地审阅协作：支持项目成员、阶段状态、按目标位置添加批注，并可将项目文件和完整研究包交给其他成员继续处理。
- AI 代理连接：支持 OpenAI 兼容代理和本地回退；真实模型密钥可以只保存在配套 Worker 中。
- DeepSeek：内置 DeepSeek Chat 与 DeepSeek Reasoner 配置预设，可使用直连令牌或通过代理调用。
- 加密云同步：通过可配置的同步服务上传 AES-GCM 密文项目，并支持本机压缩分享链接。
- 仪器直采：支持 Web Serial 串口数据流、SCPI 启动指令、实时曲线、CSV 下载和送入主数据分析流程，同时提供模拟数据流用于无硬件测试。
- 文献增强：支持 BibTeX、RIS、Zotero JSON 题录导入、扫描 PDF OCR 选项、摘要/方法/结果结构化识别、表格与公式线索，以及精确/混合语义检索。
- 科研设计模板：提供干涉精密测量、器件标定、光纤传感、光电探测、光谱频响和自定义探索模板。
- 单位与量纲检查：自动识别常见单位，提示与实验建议量纲不一致的问题，并支持横纵轴单位及换算系数。
- 不确定度预算：逐项编辑 A/B 类误差来源，自动计算合成标准不确定度和扩展不确定度，并绘制贡献图。
- 跨实验比较：选择多个实验报告，对比数据质量、重复稳定性和线性拟合，并可导出 CSV。
- 多格式导出：支持 Word、打印/保存 PDF、LaTeX、BibTeX、2400×1400 PNG 和 SVG 图表。
- 本科与研究生实验目录：保留《华科光电本科实验清单.xlsx》中 5 个课程的 47 个 A 级明确实验；重新加入原光电本科和电学扩展目录，并清理跨目录重复项后，共有 215 个实验。
- 研究生研究训练：覆盖高等光谱、超快光学、微纳光子学、先进光纤网络、量子光子学、智能仪器、生物医学光子和先进光电子材料。
- 自动分工：根据成员角色、任务依赖和当前项目完成度自动分配任务，支持改派、状态推进、工作量平衡和 CSV 导出。
- 华科核验清单专区：只保留有 A 级来源且实验名称明确的项目，已移除 36 个 B/C、无依据、题目未公开或待核实项目；剩余项目保留学期、课程、学时/学分、备注、地点/教师和证据等级。
- 原有目录恢复：通用光电本科、旧版华科光电本科培养方案和电学扩展目录重新加入，并分别通过“原光电本科”和“电学扩展”筛选查看。
- 重复项清理：移除 40 个同名或同公式的旧目录重复项；专业认知实验 16 项全部保留，不参与去重删除。
- 原始清单下载：网站提供 `hust_undergraduate_experiments.xlsx`，可在实验目录顶部下载与当前目录对应的源文件。
- 深色专业界面：采用炭黑、深海蓝、石墨灰与香槟金配色，实验课程组支持折叠，报告和论文使用暖白阅读纸张。
- 全站快速导航：支持 `Ctrl/⌘ + K` 或 `/` 打开快速跳转面板，可按区域名称或实验名称定位；`Alt + 1…9` 可直接跳到主要页面区域。导航会根据滚动位置自动更新当前区域，并提供键盘焦点、跳转状态播报和返回顶部按钮。
- 无障碍与键盘操作：新增跳到主要内容链接、统一高对比焦点框、科研功能标签页方向键切换、弹窗焦点圈定与关闭后焦点恢复；移动端快速导航不会产生横向溢出。
- 渲染性能优化：实验动画只在实验室进入视口且页面可见时持续绘制，离开视口或切换标签页后自动停止重绘；目录搜索改为短延迟合并刷新，避免每次按键重复重建全部课程卡片。
- 导入体验优化：Excel/CSV 文件解析期间显示明确的忙碌遮罩和无障碍状态，完成或失败后自动恢复；数据记录数量、文献结果数量和目录筛选数量使用状态播报。
- 统一字体系统：中文正文、展示标题、等宽数字和画布标注分别使用独立字体栈，并统一字号、行高、数字对齐和手写公式间距。
- 精致微动画：页面滚动渐入、导航指示、按钮扫光、实时讲解切换、数值滚动、质量评分、图表刷新、文献结果错峰出现和论文生成过渡，并兼容系统“减少动态效果”设置。
- 独立原理档案：每个实验均包含原理概述、理论模型、公式变量、仪器器材、推荐步骤、安全注意事项和观察判读要点。
- 可调参数演示：30 类实验模型，包括光学干涉、衍射、偏振、电路、示波器、数字逻辑、频谱、光电探测、激光、光纤、成像、嵌入式与光通信。
- 全景实验台：使用按实验名称和仿真类型匹配的器件预设，不固定使用同一套设备。215 个实验共解析出 36 种基础器件组合，并为每个实验生成独立的器件位置、连接拓扑和场景标识。设备端口按 BNC 50Ω、4 mm 香蕉插头、USB、FC/APC 光纤、2.54 mm 杜邦线等接口标准显示；当前场景中的全部器件均可拖动，光束、电缆、屏幕、波形和指标会跟随位置实时变化。
- 清晰分色光路：2D 光束采用高饱和彩色核心、白色高光和柔和外辉光；3D 光路在此之上增加深色轮廓衬底、实体彩色光管、白色细芯和双色移动光团，即使在亮色光学平台上也能保持高对比。光束从光源出发按器件顺序显示传播过程。迈克尔逊实验单独建立“入射 → 参考臂/测量臂 → 回程 → 合束 → 探测”拓扑，使用不同颜色和并行偏移区分往返光，避免回程光完全重叠；路线标签只显示与当前选中器件相关的部分，减少中心区域文字拥挤。
- 真实端口连接：2D 和 3D 光路均从器件边缘或自由空间端口出发，不再穿过器件中心。3D 会根据入射方向自动旋转反射镜、观察屏和探测器，迈克尔逊额外加入扩束镜、可变光阑、补偿板、中性衰减片和光束终止器；补偿板位于分束镜与动镜之间，更贴近真实实验摆放。
- 真正三维实验台：在“3D 实验台”中使用透视相机、立体光学平台、软阴影和实体器材。当前 83 种器材配置细分为 57 类结构模型，包括镜架、扩束镜、可变光阑、补偿板、中性衰减片、光束终止器、分束器、稳压电源、信号源、示波器、万用表、逻辑分析仪、面包板、开发板、LCD、超声模块、光谱仪、光栅、偏振器、光纤收发器、油滴室、显微镜、单摆、光电门和数字制造设备；仪器外壳使用圆角机身，并补充支脚、面板边框、散热槽、旋钮指示、金属接口、带刻度转台、PCB 元件和真实面包板孔阵。支持拖动器件、旋转总览、滚轮缩放、光路/俯视视角及“器材特写”。仪器屏幕按实验参数显示对应工程单位、量程、波形、光谱、图像和状态；单击任意器件可打开参数卡，查看型号结构、主要规格、实时读数、接口、连接关系和安全限制。
- 参考级器材质感：全部光学器件采用精密滑轨底座、锁紧旋钮、毫米刻线和四角固定件；透镜升级为双凸玻璃体并增加镀膜反射边缘，反射镜、分束器、光谱仪和相机强化金属结构。光束增加核心、内光晕和外层柔光，镜头切换与手动调控采用阻尼插值，避免生硬跳变。
- 统一物理计算链：新增独立计算引擎，为实验推演、2D/3D 仪表读数、场景指标、实验报告和论文草稿提供统一输入、公式、模型假设、计算版本和输入哈希，避免不同页面各自计算导致结果不一致。
- 单体器材调控：每台器材都有独立的位置、旋转和场景微调；反射镜可调俯仰与水平偏转，透镜和显微镜可调粗调、细准焦螺旋和通光孔径，示波器、电源、信号源、偏振器、相机、光源、光纤、热台、开发板和数据采集卡也提供各自的工程控制量。调节会实时改变模型姿态、光路曲率、仪表显示和对准指标。
- 一键搭建调试：启动后先将全部器材按两排独立工位平滑移到后方器材架，再严格按照光路和接线顺序逐个搬入正确工位。每件器材依次完成抬升、平滑平移、落下和参数校准，搬运时从其他器材上方通过，避免路径穿模；器材到位后才显示对应光路或接线，期间完整展示当前器材参数和目标值，可中途停止。3D 器件名称改为悬浮标签，不再铺在台面上遮挡相邻器材；迈克尔逊使用加宽布局和独立间距，减少大尺寸器材之间的视觉重叠。
- 常驻实时参数监看：3D 演示中持续显示当前器件的全部独立参数、位置偏差、实验主参数以及对准率、功率、频率和信噪比；拖动器材、调节滑块、切换步骤或自动调试时均会实时刷新。
- 完整实验现象总览：自动搭建完成后在 3D 画布下方展开对应实验的完整现象，包括干涉环、衍射条纹、偏振极坐标、光谱峰、时域波形、通信眼图、I–V 曲线、成像靶面和响应曲线，并同步显示统一计算值、功率、频率和信噪比。
- 阻尼式器材移动：拖动器材后位置通过弹簧阻尼跟随，松手后继续平滑减速并停在目标位置；光路和接线在移动过程中持续更新，减少生硬瞬移。
- 一次性晨光打卡：首次完成打卡后会记录自动进入状态。以后打开欢迎页或晨光提示页时显示约 1 秒的过渡动画，随后自动进入工作台，无需重复点击；提示页会在过渡层后方预取工作台页面，减少跳页白屏。
- 独立器材参数库：器材名称、规格、用途、环境条件、操作提示和安全要求可独立编辑、导入、导出和恢复默认；自定义参数保存在本机浏览器，并立即同步到器材准备页面。
- GLTF/GLB 模型资产与 LOD：每个器材默认提供程序化高精度模型和远景简化层，支持在器材参数卡中导入 `.glb`/`.gltf` 外部模型、导出当前器材为 GLB，并按距离自动在 GLB、程序化模型和轻量代理之间切换。
- 三维过程导览：3D 场景为光学、电学、激光、光纤、光谱、成像、光伏、热学、力学、生物电、数字逻辑、嵌入式和综合系统分别生成 7–8 阶段操作流程，覆盖安全准备、安装接线、基准校准、参数扫描、数据复核和关机复位；可点击步骤轨道、逐步或自动播放，每一步同时显示观察重点和安全要求，并联动光束强度、连线状态与当前器材高亮。左侧实验步骤卡和右侧实验指导面板均可在 3D 模式下一键折叠，让演示区自动铺满可用宽度，并记住用户的显示偏好。
- 精致动态场景：带光学平台、金属镜架、玻璃元件、光束光晕、仪器表盘、像素阵列和功率衰减曲线；提供场景标注、动画速度切换以及“此刻发生 / 观察重点 / 参数影响”实时导览。
- 高精度实验模型：增加统一取景框、扫描光带和比例刻尺，并补充 PCB 铜迹、半导体 PN 结剖面、器件封装、频响相位曲线、全息记录光路和通信眼图直方图。
- 数据模板与导入：提供可直接下载的 Excel 标准模板，包含均值与样本标准差公式、填写说明、单位、批号和备注列；支持 `.xlsx`、`.xls` 和多列 CSV，并可选择坐标轴、计算平均值、极值、标准差、标准误差、95% 均值区间、线性拟合、拟合残差、局部峰值和异常点检测。
- 真实感仿真数据：可设置采样点、随机噪声、系统漂移和离群点比例，生成包含量化误差、横轴抖动和可复现随机种子的实验数据；每次生成都会记录模型版本、噪声参数和随机种子，并自动写入新报告。
- 物理光线追迹：光学实验增加近轴矩阵传播与蒙特卡洛光线追迹，可显示 RMS 光斑、最大光斑半径、发散角、衍射极限、镜面误差、Michelson 光程差、相干长度和条纹可见度。
- 网格表面光线追迹：中心光线会与 3D 器材网格实际求交，记录命中位置、表面法线和阻挡器材；透镜升级为可求交的双凸球面镜片，镜架、镜片边缘和器件外壳会真实截断光线。
- 波前与物理成像：观察屏和实验现象画布使用二维波前强度生成干涉环、双缝条纹、单缝衍射、光栅谱线和 Airy 光斑，并计入光程差、相干性和镜架倾差。相机根据曝光、增益、散粒噪声、读出噪声和饱和生成像素帧；探测器根据响应度、光功率、散粒噪声和暗噪声输出光电流与信噪比。
- 物理示波器：示波器波形由采样率、模拟带宽、幅值、量化位数和噪声共同生成，可显示削顶样本、有效值和实际周期。
- 科学化 3D 场景：新增 13 类数据驱动实验环境模板，统一描述器材端口、通光孔径、抓取点、安装阶段、材料属性和接口校验。3D 光线以三路光线束显示，光阑缩小时会实时光线截断；镜架俯仰、偏转和位移会改变出射位置。支持全部光路、主光路、偏差光线三种模式。
- 3D 交互和讲解：器材拖动会搜索最近无碰撞工位，自动搭建按抓取、避障搬运、落位、粗调、精调和锁定分阶段播放，可暂停、继续和重播当前步骤。新增镜头导演、总线光路、局部剖视、小地图、固定颜色语义和不同实验族的环境光照。
- 电学网络求解：示波器、基尔霍夫/节点网络、RC 暂态、惠斯通电桥、运放和滤波实验分别调用对应模型，输出节点电压、支路电流、KCL 残差、时间常数、桥路输出、截止增益和相位等读数。
- 统一不确定度传播：主次参数的分辨率、校准和环境漂移进入蒙特卡洛传播，给出标准不确定度、95% 扩展不确定度、相对不确定度、置信区间和结果分布直方图；报告、论文证据包和统一计算快照使用同一版本与输入哈希。
- 器材条件指南：30 类交互实验均配置建议器材、关键参数、测量范围、环境条件、安全事项和初学者观察提示，并随当前实验自动切换。
- 报告版本库：每次导入数据或手动创建版本时，都会自动生成新的独立报告编号，保存在浏览器本地。
- 报告清理与撤销：支持删除单份报告、只保留最近 10 份、清理 30 天前记录和清空全部历史；清理前显示报告数量与本地占用，并可在同一会话中撤销一次误删除。
- 实验报告：使用更接近学生实验报告的表述，包含摘要、实验目的、原理、公式变量、器材步骤、数据检查、统计拟合、误差讨论、改进建议、批次对比和高偏差点。
- 报告导出：支持复制和下载 Markdown，历史版本最多保留 30 份。
- 文献检索：通过 OpenAlex 与 Crossref 检索公开学术元数据，可按 Nature、Nature Photonics、Science、Physical Review Letters、Optics Express 和 Science Advances 筛选。
- 引用管理：保存文献题名、作者、期刊、年份、DOI、被引次数和摘要线索，可导出 BibTeX。
- 论文工作台：将详细实验报告与所选文献组合，生成包含摘要、引言、原理、方法、结果、讨论、结论和参考文献的论文初稿。
- 证据约束型 AI 写作：通过已配置的 DeepSeek 或兼容代理执行“汇总报告与文献证据、读取统一计算快照、生成论文草稿、核验引用编号和 DOI”四阶段工作流；AI 输出会带“未经审核”标识，并附可追踪证据表与自动格式检查，不允许模型自行补充实验数据或文献结论。
- 照片质量检查：检查实验照片尺寸、亮度和清晰度，并在下一份报告中引用。
- 持续反馈入口：通过公开 GitHub Issue 提交实验补充建议、问题反馈或直接进入项目主页；页面明确提醒不要公开姓名、学号、手机号和未公开实验数据。

## 运行方法

在最直接的方式是在程序目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

脚本会启动本地静态服务器并打开浏览器。

也可以执行：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。根路径会自动进入 `advanced.html`。

## 当前边界

- 本科实验目录已切换为附件清单，原通用课程映射不再作为默认本科目录显示。
- 华科核验清单按附件中的 A 级且名称明确的项目建立。B/C、无依据、题目未公开和待核实项目已从该核验清单删除，原始 Excel 仍可下载用于追溯。
- 所有演示均为软件仿真，不替代真实仪器操作和实验安全规范。
- 全景实验台使用教学近似几何和信号模型，用于理解器件关系与操作影响，不替代真实光路追迹、仪器校准和专业仿真软件。
- 三维实验台是交互式教学仿真，器材比例、材质和测量值经过教学简化；真实实验必须以仪器铭牌、实验室安全规定和指导教师要求为准。
- 自动报告使用结构化模板，并结合导入数据生成统计、拟合、异常点和趋势分析；提交前仍需人工核对。
- 文献检索需要联网，使用 OpenAlex 与 Crossref 公共元数据 API；软件不自动下载或阅读论文全文。
- 论文工作台使用结构化学术写作模板，不会虚构实验结果；文献引用处的具体结论仍需阅读原文后核实和改写。
- 实验照片只检查基础质量，不识别装置或读数。
- 数据与历史报告只保存在当前浏览器，不会上传服务器。
- 文献全文和科研项目资料同样优先保存在浏览器本机；大型 PDF 使用 IndexedDB，清理站点数据会一并删除。
- 文献结论不会由软件自动判定为支持或反驳，必须由用户阅读原文并填写证据卡片。
- 当前审阅协作是单机流程，不提供账号、实时同步或多人权限；需要共享时应导出项目文件或可复现研究包。
- 研究生实验目录采用典型光电信息研究训练方向扩展，具体课题、平台和开设学期应以所在学院及导师安排为准。
- AI 代理和云同步服务需要单独部署；配套 Cloudflare Worker 源码位于 `server/`，真实模型密钥不应写进前端。
- PDF 直接导出使用浏览器打印为 PDF；扫描 PDF 可以开启离线 OCR，简体中文和英文语言包已随网站托管。
